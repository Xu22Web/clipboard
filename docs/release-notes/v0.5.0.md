## 新增

- 改主题不重启：设置窗口保存后立即重绘，面板与托盘菜单下次打开时换成新配色，通知区图标一并重画
- 设置窗口新增最小化按钮，标题区可拖动移动窗口
- 设置窗口打开时按热键会先最小化它并打开历史面板，面板关闭后窗口恢复原样

## 修复

- 托盘打开设置后再打开「关于」，关闭设置后设置窗口再也打不开
- 插件右键菜单、条目编辑卡片、悬停预览说明与面板底部计数显示英文
- 设置项的灰置原因与数据目录提示显示英文

## 兼容

- 旧版 `clipboard.ini` 可直接沿用
- 安装包 `clipboard-0.5.0.zip`，同附 `SHA256SUMS.txt` 供校验
