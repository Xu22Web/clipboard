与 0.1.1 相比的变化。

## 新增

- 设置窗口：左侧按页分组，行内直接改值，改动先暂存再一次「保存」，另有「放弃」与「恢复默认」
- 设置窗口可录制快捷键，打开时显示当前生效的热键
- 数字按其单位显示与输入，短按以「+」连接成链
- 设置页末尾增加「关于」页：版本、数据格式、条数与已加载插件
- `clipboard settings <页名>` 直接打开某一页

## 修复

- 托盘与命令行都改在常驻进程内打开设置窗口，一个会话只有一个窗口
- 保存后关闭窗口会重启一次常驻进程，让新值生效
- 数字输入框不再把光标停在末位数字上
- 悬停与开关动画只重绘各自区域，不再留下色块

## 兼容

- 旧版 `clipboard.ini` 可直接沿用
- 安装包 `clipboard-0.2.0.zip`，同附 `SHA256SUMS.txt` 供校验
