与 0.3.7 相比的变化。

## 新增

- 中文界面：面板、托盘菜单、设置窗口与各处提示都由语言包提供，在设置窗口里切换 `English` / `简体中文`
- 语言项按语言自己的名字显示；改语言不重启常驻进程，设置窗口立即刷新，面板与托盘菜单下次打开时生效
- 设置窗口左侧分组显示图标与名称
- 插件可用语言包命名标记词（`mark.<插件>.<字符>`），缺键时用插件自己的词

## 修复

- 设置 `Language` 不生效
- 发布包内的中文语言包不可用
- 「恢复默认」把 `Plugins` 写成空值
- `clipboard config` 报表缺少 schema 声明的一部分设置键

## 兼容

- 旧版 `clipboard.ini` 可直接沿用；`Plugins=` 为空仍表示启用全部插件
- 安装包 `clipboard-0.4.0.zip`，同附 `SHA256SUMS.txt` 供校验
